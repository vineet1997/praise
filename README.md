# For Priya

A cinematic, single-page tribute in which a field of scattered words gradually
becomes a declaration of love. The experience is driven by one scrubbed GSAP
timeline and ends in a calm dedication.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite. Create a production build with:

```bash
npm run build
```

## Edit the wording

All editable wording lives in `src/content/tribute.ts`. The typed `tribute`
object contains the recipient and sender names, opening message, instruction,
floating words, poem lines, final line, dedication, and signature.

Each poem line supports:

- `keyWord`: the word that receives visual emphasis;
- `emphasis`: `quiet`, `medium`, or `strong`;
- `reveal`: one of the related reveal variations;
- `section`: either the early `simple` passage or later `personal` passage.

Keep a key word lowercase in `floatingWords` if you want it to visibly travel
from the word field into an early poem line.

## Animation architecture

`src/hooks/useTributeTimeline.ts` creates the pinned master ScrollTrigger
timeline. It controls the opening, the gradual organisation of the word field,
line-by-line poem assembly, convergence, and final dedication. Lightweight
pointer and ambient drift run on inner word elements so they do not overwrite
the scroll transforms on the outer wrappers.

The deterministic layout is generated by `src/lib/seededRandom.ts`, so every
refresh preserves the composition.

## Visual theme

The palette, type scale, aurora, grain, blur, and mobile layout are controlled
in `src/styles/global.css`. The aurora markup is isolated in
`src/components/AuroraBackground.tsx`.

To reduce animation complexity further on phones:

- lower the mobile scroll distance in `useTributeTimeline.ts`;
- reduce the mobile word limit in the `nth-child` rule in `global.css`;
- reduce blur, convergence size, or word scale in the mobile media query.

The site automatically supplies a much shorter, unpinned reading experience
when `prefers-reduced-motion` is enabled.

## Deploy to Vercel

Import the repository into Vercel and keep the detected Vite settings:

- Build command: `npm run build`
- Output directory: `dist`

No environment variables, server functions, or backend services are required.
